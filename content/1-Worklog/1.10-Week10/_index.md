## Week 10 Objectives

In week 10, the primary objective was to study the **AWS cost management and security improvement** topics. This belongs to the **Optimize / Optimizing system** phase in the AWS Cloud Journey, focusing on improving system efficiency, security protection, cost control, and operational management after deploying workloads on AWS.

Main topics covered during this week:

* Understanding the fundamentals of AWS cost optimization strategies.
* Learning how to use **AWS Budgets** for monitoring spending and configuring cost notifications.
* Exploring **AWS Cost Explorer** to analyze AWS service consumption and spending patterns.
* Studying **AWS KMS** for encryption key management and data protection.
* Understanding **AWS WAF** for protecting web applications and APIs against common threats.
* Exploring **AWS Security Hub** to evaluate security posture and compliance standards.
* Reviewing AWS best practices for maintaining secure and cost-efficient systems.

## Week 10 Achievements

### Overview

This week, I focused on learning AWS services related to **cost optimization and system security enhancement**. The learning content was divided into two major areas: cost management through **AWS Budgets** and **AWS Cost Explorer**, and security improvement through **AWS KMS**, **AWS WAF**, and **AWS Security Hub**. These services help organizations monitor expenses, protect important data, and improve the overall security posture of AWS environments.

### Knowledge gained

After completing week 10, I have learned:

* The importance of cost optimization in designing and operating AWS-based systems.
* How to configure **AWS Budgets** to monitor spending, define thresholds, and receive cost alerts.
* How to use **AWS Cost Explorer** to analyze expenses based on services, time periods, accounts, and resource tags.
* That **AWS KMS** provides centralized key management and encryption capabilities to secure data stored and processed by AWS services.
* That **AWS WAF** provides protection for websites, APIs, and applications by filtering malicious traffic, preventing common attacks, and controlling unwanted requests.
* That **AWS Security Hub** collects security findings and evaluates AWS environments against security standards and best practices.
* The importance of combining financial monitoring, IAM access control, encryption mechanisms, and application-layer protection to build secure AWS systems.

---

## Practice

During the learning and hands-on process, I was able to:

* Access AWS Billing and Cost Management features through the AWS Console.
* Analyze AWS service usage and identify cost consumption patterns.
* Create AWS Budgets to monitor monthly spending limits.
* Configure notification alerts when usage or costs exceed expected thresholds.
* Use Cost Explorer to visualize and compare AWS service expenses.
* Explore AWS KMS concepts including Customer Managed Keys and AWS Managed Keys.
* Understand how AWS KMS supports encryption for services such as S3, EBS, and RDS.
* Explore AWS WAF components including Web ACL, Rules, and Managed Rule Groups.
* Understand how AWS WAF integrates with CloudFront, Application Load Balancer, and API Gateway.
* Review AWS Security Hub findings and understand their role in security assessment.
* Identify common configuration issues such as disabled Cost Explorer, missing budgets, insufficient IAM permissions, incorrect WAF rules, or unencrypted sensitive data.
